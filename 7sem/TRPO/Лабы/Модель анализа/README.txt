Лабораторная работа «Модель анализа» — ИС «Экскурсионное бюро»
=================================================================

Состав папки:
  Отчет_Модель_анализа.docx  — готовый отчёт (титульный лист, 4 раздела,
                               рисунки 1–7 и таблицы 1–9)
  Диаграммы/                 — исходники и изображения диаграмм
  Примеры/                   — пример оформления, предоставленный преподавателем

Перечень диаграмм (PlantUML):
  01_Модель_предметной_области.puml/.png   — диаграмма классов анализа
                                             (атрибуты классов — из логической
                                             схемы данных курсовой работы)
  02_Состояния_Заявки.puml/.png            — модель состояний «Заявка»
  03_Состояния_Экскурсии.puml/.png         — модель состояний «Экскурсия»
  04_Варианты_использования_Клиент.puml/.png       — UC, фрагмент 1
  05_Варианты_использования_Гид.puml/.png          — UC, фрагмент 2
  06_Варианты_использования_Руководитель.puml/.png — UC, фрагмент 3
  07_Контекст_C4.puml/.png                 — контекстная диаграмма C4

Как перерисовать (при наличии Java и plantuml.jar):
  java -jar plantuml.jar -tpng -charset UTF-8 Диаграммы/*.puml

Примечания:
  - диаграмма классов построена с ортогональной трассировкой связей
    (skinparam linetype ortho) — для её перерисовки обязателен Graphviz;
  - для аккуратной раскладки остальных диаграмм Graphviz также рекомендуется;
  - диаграмма C4 использует стандартную библиотеку C4-PlantUML
    (входит в состав PlantUML).
