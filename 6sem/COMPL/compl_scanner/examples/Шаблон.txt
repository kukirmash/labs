Программа = Заголовок Блок.
Заголовок = КлючевоеСловоЗаголовка КлючевоеСловоИмени ";".
КлючевоеСловоЗаголовка – см. свой вариант в табл. 1
КлючевоеСловоИмени – фамилия и инициалы студента без пробелов, например, "PavlovLA"
Блок = РазделОбъявлений РазделОператоров.
РазделОбъявлений – см. свой вариант в табл. 2
Тип = Имя_Типа | СоставнойТип.
Имя = Буква { Буква | Цифpа }.
СоставнойТип – см. свой вариант в табл. 3
РазделОператоров = "start" ПоследОператоров "stop".
ПоследОператоров = Оператор { ";" Оператор } ";".
ПоследОператоров = Оператор { ";" Оператор }.
Оператор = ОператорПрисваивания | УправляющийОператор.
ОператорПрисваивания = Переменная Присваивание Выражение.
Переменная = Имя_Переменной | ОбращениеКЭлементуСоставногоТипа.
ОбращениеКЭлементуСоставногоТипа – см. свой вариант в табл. 3
Присваивание – см. свой вариант в табл. 1
УправляющийОператор – см. свой вариант в табл. 4
Выражение = ПростоеВыраж [ ОперОтношения ПростоеВыраж ].
ОперОтношения = "<" | "<=" | ">" | ">=" | Равно | Неравно.
ПростоеВыраж = [АддитОперация ] Терм { АддитОперация Терм } | Терм { ЛогичИЛИ Терм }.
АддитОперация = "+" | "–".
Терм = Фактор { МультОперация Фактор } | Фактор { ЛогичИ Фактор }.
МультОперация = "*" | "/".
Фактор = Константа | Пеpеменная | "(" Выражение ")" | ЛогичНЕ Фактор.
Равно, Неравно, ЛогичИЛИ, ЛогичИ, ЛогичНЕ – см. свой вариант в табл. 1
Константа = Число | "true" | "false".
Число = Целое [ "." Целое ].
Целое = Цифpа { Цифpа }.
